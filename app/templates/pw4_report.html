PRACTICAL WORK 4 · PYTORCH

CPU, GPU and TPU.

Report of PW4: a small CNN trained on CIFAR-10 with PyTorch on Google Colab, and the comparison of the computation times on different hardware.

1. What we did

The given notebook trains a small convolutional network (2 convolution layers, 3 dense layers, about 62,000 parameters) on the CIFAR-10 dataset (50,000 training images of 32×32 pixels, 10 classes: plane, car, bird, cat, deer, dog, frog, horse, ship, truck) for 2 epochs with batches of 4 images, then tests it on the 10,000 test images.

We ran the same notebook on our laptop and on Google Colab with the three runtime types (Runtime > Change runtime type: CPU, GPU T4, TPU v5e-1) and recorded the training time, the inference time and the accuracy. Notebook: notebooks/PW4_pytorch_cpu_gpu_tpu.ipynb.

2. What we had to fix in the notebook

  • Errors 1, 2 and 3 (Input type and weight type): the model was on the GPU but the test images stayed on the CPU. In the first test cell the code moved inputs (from the training loop) instead of images. We send images and labels to the device in the three test cells.
  • The inference time was not measured, we added it.
  • The GPU and the TPU work asynchronously, so we wait for them (synchronize) before reading the time, otherwise the time is wrong.
  • TPU: the notebook only looked for torch_xla, which is not installed on the new Colab TPU runtime, so it ran on the CPU without any error. We choose the device with torch.accelerator (GPU or TPU) and keep torch_xla for older runtimes.
  • On the TPU runtime the DataLoader worker processes crashed the session, so we use num_workers=0 there.

Conclusion

  • The TPU was the fastest for training and the GPU for inference, but the differences are small: the GPU is only 1.4 times faster than the Colab CPU.
  • The reason is the batch size of 4 and the very small model: each step sends only 4 images to the accelerator and does very little computation, so most of the time is spent on transfers and loading the data. With bigger batches and a bigger model, the GPU and the TPU would be much faster.
  • Our laptop CPU was faster than the Colab CPU, so for such a small model a GPU is not really needed.
  • The accuracy is the same everywhere (about 55 %): the hardware changes the speed, not what the model learns.
  • Using the TPU with PyTorch is not automatic: without the right library the code runs on the CPU without any error.
